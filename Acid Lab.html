What's inside

Everything you need to create

⬡
Modular Canvas
Drag, wire and arrange 30+ studio apps on an infinite zoomable workspace. Connect anything to anything.
🎛
30+ Studio Apps
Synths, sequencers, effects, utilities — wavetable, granular, distortion, reverb, EQ, sidechain and more.
〜
Real-time Audio Engine
Built on the Web Audio API with a low-latency graph. No plugins, no DAW — runs entirely native in Electron.
⬤
Step Sequencer & Piano Roll
16-step melodic sequencer with velocity bars and scale quantisation. Drives any connected synth.
◈
Wire Routing
Fan-out wires, rubber-band multi-select, drag to workspace. Build complex signal chains visually.
↑
Auto-updates
New versions install automatically in the background. Always stay on the latest build.
